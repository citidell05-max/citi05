# Arcane Horizon

Gamified study companion (quests, focus timer, XP, games, themes).

## Open the app

1. Use the **`cursor/arcane-horizon-study-app-b7d1`** branch (not empty `main`).
2. Download / clone the **whole folder** (needs `index.html` + `assets/` + `sounds/` + JS files).
3. Open with a local server from the project root:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

Hard refresh (`Ctrl+Shift+R` / `Cmd+Shift+R`) if themes look cached.

## Themes

Tap a picture under **Themes**. Default is **Arcane Sunrise** (branded sunrise background).
